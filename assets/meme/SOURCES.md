# Происхождение картинок врезки

## ok.png

Знак «OK» (U+1F44C) из Noto Emoji — открытого набора эмодзи Google:
`png/512/emoji_u1f44c.png` в github.com/googlefonts/noto-emoji,
ветка main, коммит `8998f5dd683424a73e2314a8c1f1e359c19e8742`.

Что изменено: знак вырезан по непрозрачной области, увеличен до 858 px
по высоте и положен по центру тёмного кадра 1080×1920 (фон `#0E0C10`) —
в той же компоновке, что и прежняя картинка.

Прежняя была нарисована на эмодзи Apple. Этот рисунок лицензирован только
для устройств Apple, и в открытом репозитории и в роликах канала ему
не место.

## Лицензия

README репозитория относит «tools and most image resources» к Apache 2.0
и ссылается на корневой LICENSE, но сам этот файл 29.07.2024 заменён
на SIL OFL 1.1 (коммит `254596e5f8` «Update LICENSE to OFL»). Обе лицензии
разрешают коммерческое использование и распространение изменённых версий;
какую из них считать действующей для картинок, репозиторий однозначно
не говорит, поэтому рядом лежат оба текста:

- `LICENSE-noto-emoji-OFL.txt` — LICENSE из main на момент выгрузки;
- `LICENSE-noto-emoji-Apache-2.0.txt` — LICENSE до замены
  (коммит `41e31b110b4eb929dffb410264694a06205b7ad7`).
