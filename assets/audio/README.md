# Подложки для клипов

Сюда складываются музыкальные петли, из которых машина клипов берёт звук.
Папка лежит в iCloud Drive, поэтому файлы можно сохранять сюда прямо
с телефона: «Поделиться» → «Сохранить в Файлы» → iCloud Drive →
MUZ AI → assets → audio.

## Имена файлов

    <настроение>-<номер>.mp3

Настроение — одно из трёх:

| Имя | Звук | Под какие рубрики |
|---|---|---|
| `dark` | мрачное, разреженное, зловещее | ОТКУДА НОГИ, МЕЖДУ СТРОК |
| `aggressive` | тяжёлое, злое, с давлением | ВЕРДИКТ, ИНФОПОВОД |
| `nostalgic` | мутное, меланхоличное, плёночное | ЛЕГЕНДА, архивное |

Например: `dark-01.mp3`, `aggressive-03.mp3`, `nostalgic-02.mp3`.

Группы названы по настроению, а не по жанру, намеренно: смена музыкального
направления не потребует правок кода. Рубрика МЕМ берёт что попадётся —
там звук вторичен.

## Требования

- Инструментал. Вокал перебивает текст на экране
- От 30 секунд: из трека режется фрагмент
- mp3 или wav, перекодировать не нужно — это сделает ffmpeg при сборке
- Лицензия: коммерческое использование разрешено, атрибуция не требуется

## Откуда брать

Pixabay Music, при нехватке — Mixkit. Как искать, какие теги рабочие
и почему не подходят «free type beat» с ютуба — в [GROWTH.md](../../GROWTH.md),
раздел «Что мешает полной автономности».

**Не класть сюда** треки, о которых пишет канал: площадки сверяют аудио
с базой правообладателей, и канал, живущий на страйках, не построишь.
