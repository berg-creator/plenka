# Рубрика ОПРОС

Нативный опрос Telegram. Дешёвый способ поднять вовлечённость и понять, кто в канале сидит.

## Задача

Вопрос, на который хочется ответить не задумываясь, но по которому потом спорят.

## Что на входе

JSON со списком артистов и тегов из базы канала. Поле `asked` — вопросы прошлых опросов:
не повторяй ни вопрос, ни его тему. Про «с чего всё началось» спрошено — ищи другое.

## Требования к формату

Ответ строго в JSON:

```json
{
  "question": "текст вопроса, до 250 знаков",
  "options": ["вариант 1", "вариант 2", "вариант 3", "вариант 4"],
  "is_anonymous": true
}
```

- В поле `text` — только этот JSON. Без заголовка, вступления, списка с эмодзи и просьбы
  голосовать реакциями: это нативный опрос, кнопки рисует сам Telegram. Текст вместо JSON — брак.
- От 2 до 4 вариантов. Каждый — до 100 знаков.
- Варианты одного рода и отвечают на один вопрос. Из списка артистов бери только тех,
  кто к вопросу подходит, а не всех подряд.
- Один вариант может быть шуткой — имя не из списка, которое знает вся страна, хоть с эстрады
  (владелец, 04.10.2026: в опрос про первого любимого исполнителя просился SHAMAN).
  Не больше одного: шутка смешна рядом с честными вариантами.
- Вопрос без вводных: не «А как вы считаете, друзья…», а сразу суть.

## Хорошие типы вопросов

- Спорное сравнение: два артиста, два альбома, две эпохи.
- Признание: «сколько раз ты на самом деле дослушал этот альбом до конца».
- Самоидентификация: «с чего у тебя всё началось».
- Проверка на своих: «что из этого ты слушал до того, как оно попало в тикток».

## Чего избегать

- Вопросов с очевидным ответом — по ним не спорят.
- Вариантов «другое» и «затрудняюсь ответить» — они забирают голоса и ничего не говорят.
- Тем вне музыки.
