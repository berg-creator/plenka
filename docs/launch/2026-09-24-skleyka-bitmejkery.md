## Что писать

Где метка: вместо `XXX` — метка из таблицы, например `skleyka_bm_jidixeed`.

Метки `skleyka_bm_*` бот считает по полной метке (`service.BEAT_LABEL`, 24.09.2026): кто из битмейкеров привёл людей, видно в `python -m src.service --sources`.

Бесплатные тайп-биты на YouTube почти все с условием «бесплатно только для некоммерческого
использования». Поэтому YouTube-битмейкеру не говорим «WAV для площадок» как главный плюс:
выходит, будто зовём выпускать трек без лицензии. Говорим, что готовый трек подталкивает
купить лицензию.
