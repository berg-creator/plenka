## Как искал

- **Ключа YouTube Data API на машине нет**: `GOOGLE_API_KEY` и `YOUTUBE_API_KEY` в `.env`
  пустые (ключ живёт только в секретах GitHub). Поэтому `commentThreads.list` с `searchTerms`
  и `allThreadsRelatedToChannelId` недоступны. Квота API не тронута, SerpApi не тронут.
- Замена: `yt-dlp` (стоит в системе). Поиск роликов — `ytsearchN:запрос`, комментарии —
  выгрузка до 400–700 штук на ролик (сортировка «популярные», под клипами — «новые»),
  ответы в ветках — до 5 на ветку. Фильтр по словам («бот», «подскажите», «как найти»,
  «где послушать», «есть сервис», «как узнать», «кто знает», «как перенести», «не работает»,
  «пропал») — локально, регулярными выражениями, потом чтение глазами.
- Объём: 45 поисковых запросов, выгружены комментарии 83 роликов (у трёх комментарии закрыты),
  всего **11 658 комментариев**. Имена авторов не сохранялись вовсе.
- Даты: YouTube отдаёт только «6 месяцев назад». Даты ниже — приблизительные, отсчитаны
  от 18.09.2026 и помечены «≈». Лайки и число просмотров — со страницы на 18.09.2026.
- Ссылка на комментарий: `https://www.youtube.com/watch?v=<ролик>&lc=<комментарий>`.
  Все цитаты получены выгрузкой со страницы ролика, то есть открыты мной (`opened=true`).
- Побочно: 1 запрос WebSearch (какие боты переноса уже есть), `curl t.me/yamusic_export_bot`
  и `curl ymusicexport.ru` (оба отвечают).

**Заметка сборщика.** Польза не зависит от размера канала, аудитория совпадает (уходят из-за цензуры рэпа),

## Тупики

1. **API YouTube.** Ключа на машине нет — `searchTerms` и обход всех веток канала
   (`allThreadsRelatedToChannelId`) не сделаны. С ключом из секретов GitHub это можно повторить за
   ~200 единиц квоты; `yt-dlp` берёт только верх выдачи под каждым роликом, и редкие вопросы без лайков
   в больших ветках (3–4 тыс. комментариев) могли не попасть.
2. **Рэп-клипы, сливы, разборы альбомов** (7 роликов, ~1 350 комментариев, включая клип на 3,86 млн):
   вопросов о сервисах практически нет — там спорят о тексте и об артисте. Один «А где послушать то
   просто трек». Под клипами спрос не ищется.
3. **Ролики «как продвигать музыку»** (5 роликов, ~370 комментариев): вопросы общие («КАК делать, вот это
   где узнать?»), к инструменту не сводятся; заметно лишь «Дайте ссылку на телеграм бота» под роликом,
   где блогер сам обещал бота.
4. **Минус, тональность, BPM, обложка, сниппет для TikTok:** под роликами спрашивают «где скачать
   программу» и про ошибки в ней, «есть ли бот» не спрашивает никто. Сигнала нет.
5. **Статистика прослушиваний «как Wrapped» для Яндекса:** поиск роликов ничего целевого не дал, в
   комментариях один голос про убранный скробблинг.
6. **Дата комментария** точнее «N месяцев назад» без API не достаётся.
