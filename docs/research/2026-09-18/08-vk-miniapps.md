## Находки по убыванию силы

### 1. «Сравнить музыкальный вкус с другом: процент совпадения и общие треки»

**Кто спрашивает:** обычные слушатели Яндекс Музыки, пары, друзья; часть — пришедшие из Spotify, где был Blend («Синтез»).

**Сколько:** идея №1 на всём форуме Яндекс Музыки — **+18 266 голосов**, 59 комментариев, **20 слитых дубликатов** от разных людей (следующая по голосам идея — 5 198). Плюс отдельные незакрытые темы: +31 и +6. Тема заведена 7 лет назад, обновлялась год назад, дубликаты — 1–2 года назад.

**Цитаты:**
- «В виде % пересечения вкусов. […] Это был бы крутейший элемент соц.сети для общения и знакомств, потому что музыка может сказать о челевеке лучше чем он сам» — [тема «Поиск людей с тем же профилем вкусов»](https://yandexmusic.userecho.ru/communities/45/topics/421-poisk-lyudej-s-tem-zhe-profilem-vkusov)
- «В этой функции будет 2 кнопки: 1 выдать код 2 написать код. 1пользователь получает код, а 2пользователь вписывает его. Яндекс Музыка будет выдавать про процентам на сколько похож вкус пользователей» — там же, дубликат «Сравнение музыки»
- «Хотелось бы иметь возможность выводить список одинаковых песен с другим пользователем (сравнивая мои "любимые" и его). Например, когда с другом хочется послушать музыку и хочется, чтобы были песни, которые нравятся нам обоим. Сейчас приходится открывать плей-лист одного человека и другой "руками" ищет то, что ему нравится» — там же, дубликат «Вывод общих треков»
- «Я предлагаю добавление функции проверки совместимости музыкальных вкусов у друзей» — там же
- «два пользователя Я.Музыки могли сравнить свои плейлисты "Мне нравится" на совпадение треков, исполнителей и т.д. и понять, насколько их вкусы в музыке совпадают. Данную идею можно воплотить, например, на 14 февраля» — [отдельная тема, +31](https://yandexmusic.userecho.ru/communities/45/topics/14488-interaktiv-po-sravneniyu-plejlistov-polzovatelej)
- «Возможность сравнивать музыкальный вкус с друзьями, приложение будет выдавать в % схожесть плейлистов +ни у кого нету» — [отдельная тема, +6, год назад](https://yandexmusic.userecho.ru/communities/45/topics/15319-sravnivat-treki-s-druzyami-shozhest-vkusa-v-muzyike)

**Чем закрывают сейчас:**
- Яндекс 22.07.2026 запустил «Мою волну на двоих»: общий поток рекомендаций для двух человек по ссылке-приглашению, **только с Плюсом**, **процента и списка общих треков не показывает** ([Яндекс, 22.07.2026](https://yandex.ru/company/news/22-07-2026-03)). В подсказках Google и Яндекса уже стоит «моя волна на двоих не работает».
- VK Музыка 01.09.2022 делала совпадение вкуса со 100 знаменитостями (пост — 630 лайков; рядом с датой стоит число 1 054 — по вёрстке это комментарии, [vk.ru](https://vk.ru/wall-147845620_441505)); между двумя обычными людьми — нет.
- Spotify Blend — в России недоступен без обхода. Last.fm Taste-o-meter убран давно, сам Last.fm с марта 2026 закрыт для России (см. п. 2).
- Telegram-бота для этого не нашёл (SerpApi, 18.09.2026).

**Чего не хватает:** одной цифры и одного списка — «мы совпадаем на N %, вот наши общие артисты и треки», без Плюса и между разными площадками (он в Яндексе, она в VK).

**От размера канала не зависит:** да. Нужны два человека, и второго приводит первый — функция сама себя раздаёт («сравни со мной»).

**Реализуемость, проверено руками:** открытые лайки и плейлисты Яндекс Музыки отдаются по логину без ключа (`api.music.yandex.net/users/<логин>/likes/tracks`). Два логина → пересечение по артистам и трекам. Проверить: открыта ли фонотека у пользователя по умолчанию; отвечает ли Яндекс на запросы с адресов GitHub Actions (или нужен VPS). VK такого доступа не даёт вовсе.

**Законно ли:** читаются только данные, которые человек сам держит открытыми; API неофициальный — Яндекс может закрыть его или поставить капчу в любой день. Логины — данные о людях: только в приватное хранилище.

**Оговорка:** соседствует с отвергнутым «разбором вкуса». Отличие — здесь не оценка одного человека ботом, а сравнение двух людей между собой по фактам (общие треки), и именно это просят 18 тысяч голосов.

### 2. «Last.fm закрылся для России: как теперь скробблить и смотреть свою статистику»

**Кто спрашивает:** меломаны со стажем — те, кто «наслушивает 100000–200000 минут в год»; пользователи Яндекс Музыки, Spotify, AIMP, foobar2000.

**Что сломалось и когда:**
- Яндекс Музыка убрала привязку Last.fm: новым пользователям — 4 года назад (дата темы на форуме), остальным — в конце декабря 2024 (по заголовкам Пикабу от 27.12.2024 и DTF; сами страницы не открылись).

Плашка поддержки: «Due to current restrictions, we are unable to offer access to the Last.fm website in Russia at this time» ([форум Last.fm, с 19.03.2026](https://support.last.fm/t/did-last-fm-just-block-russia/117851)).

**Сколько:** тема «Вернуть скроблинг Last fm» — **+5 198 голосов, 1 939 ответов, 194 страницы**, вторая на форуме Яндекс Музыки; соседняя тема-петиция — +182. Пост на DTF об уходе Last.fm — 7,9 тыс. просмотров (31.03.2026). В подсказках поиска: «last fm не работает в россии 2026», «last fm обход», «last fm zapret», «ласт фм заблокировали в россии». Бот `@lastfmrobot` (англоязычный, «Supports lastfm, librefm and listenbrainz») показывает статистику — число его пользователей на странице t.me не указано. Similarweb по last.fm: 24,5 млн визитов за август 2026, России в пятёрке стран нет.

**Чего не хватает:** способа видеть свою статистику и «что сейчас играет» без VPN; скробблинга с колонки и из Яндекс Музыки без танцев.

**Что тут может бот — честно.** Серверы проекта стоят вне России (GitHub Actions), ключ Last.fm API в проекте уже есть. Бот может **показывать**: топ недели/месяца/года, коллаж, совпадение с другом (тот же п. 1, но по Last.fm) — без VPN, по имени профиля. **Скробблить за человека бот не может**: для этого надо знать, что у него играет, а это либо клиент на устройстве, либо его токен Яндекса на сервере — второе есть у самоделок на GitHub, но это хранение чужих ключей и неофициальный API. То есть бот закрывает половину боли (смотреть), а не главную (записывать).

**От размера канала не зависит:** да.

**Законно ли:** чтение по официальному API Last.fm — да. Но Last.fm сам объявил, что «не может предоставлять доступ в России»; бот-посредник этот запрет обходит — условия API стоит перечитать до постройки. Риска для пользователя нет.

- **Боты**: `@wholovesmusicbot`, которого советовали iGuides и «Код Дурова» и до сих пор советуют статьи 2025–2026 годов (zenama, 14.06.2025; softsalad, 09.04.2026 — по выдаче), — **по этому адресу теперь канал на 632 подписчика, бота нет** (t.me, 18.09.2026). `@yamusic_export_bot` жив, но принимает не ссылку, а HTML-код плейлиста. `@HiSpotifyHelperBot` — только Apple Music → txt (пост автора на DTF, 12.09.2025: 4,8 тыс. просмотров; «Специальные сервисы — либо платные, либо неработающие, либо с подпиской»).
- Рабочий путь Яндекс → Spotify сегодня: плейлист → «HTML-код» → бот → txt → TuneMyMusic под VPN → вход в Spotify. **Пять шагов и VPN.**

**Что тут может бот — честно.** Прочитать открытый плейлист по ссылке он может (Яндекс — проверено без ключа; Spotify, Apple Music, YouTube — открытые страницы и API). **Записать в чужую фонотеку — нет**: для этого нужен вход человека в его аккаунт, а VK и Яндекс такого входа сторонним не дают. Остаётся: ссылка → аккуратный список «Артист — Трек» (txt/csv) одним сообщением, без HTML-кода, VPN и лимита 500; и ссылка на плейлист Яндекса в том виде, который принимает мини-приложение VK (см. цитату про «ссылка поменяется через секунду»). Это убирает 2–3 шага из пяти, но не последний.

**От размера канала не зависит:** да. **Разовая:** перенёс — и ушёл, повода оставаться подписанным нет.

**Законно ли:** список названий — не музыка, авторского права не касается. Чтение Яндекса — неофициальный API, тот же риск, что в п. 1.

### 4. «Моя статистика прослушиваний в любой день, а не раз в год»

**Кто:** слушатели Яндекс Музыки и VK Музыки, привыкшие к Spotify/Last.fm.

**Сколько:** «Добавить статистику своего профиля» — +241, **12 дубликатов**; «Экспорт полной истории прослушиваний» — +56; всего 47 тем по слову «статистика». Подсказки: «статистика яндекс музыки личная как посмотреть», «статистика яндекс музыки за месяц», «как посмотреть статистику в вк музыке», «как посмотреть свою статистику в вк музыке», «как посмотреть сколько раз слушал песню в яндекс музыке».

**Цитаты:**
- «Сделать статистику по типу годовых итогов, только в постоянном доступе. Хотелось бы видеть сколько часов/минут ты потратил с начала года и на сегодняшний день на музыку» — [форум Яндекс Музыки](https://yandexmusic.userecho.ru/communities/45/topics/10441-dobavit-statistiku-svoego-profilya)
- «хочется чтоб была возможность всегда знать эту информацию, а не только перед НГ)» — там же, дубликат
- «Сейчас экспорт данных о прослушиваниях […] возвращает ~1500 последних треков без имён исполнителей. В текущем виде данные не пригодны для анализа или их переноса в другие сервисы» — [там же, +56](https://yandexmusic.userecho.ru/communities/45/topics/14471-eksport-polnoj-istorii-proslushivanij); ответ месяц назад: «Теперь архив возвращает всего лишь 428 трека...»; «После отключения интеграции с ластфм - это необходимая функция!» (+25)
- «У моего друга в любимых исполнителях показывается статистика кого и сколько он слушал, а у меня нет такого. Где посмотреть или включить эту статистику?» — [Ответы Mail](https://otvet.mail.ru/question/267396224); ответ 5 месяцев назад про sp.yandex.ru/stats: «По этой ссылке статистика не учитывается больше […] Видимо яндекс убрал эту функцию»

**Чем закрывают:** Яндекс с 19.02.2025 показывает «Ваш топ месяца» по артистам (CNews — по выдаче, страницу не открывал), «Распаковку» в декабре, «Итоги лета» для Плюса; VK — только итоги года мини-приложением. Минуты, треки, счётчик прослушиваний — нет.

**Бот тут почти бессилен:** история прослушиваний закрыта, без ключа человека её не прочесть, выгрузка Яндекса отдаёт 428 треков без артистов. **Тупик по реализуемости при живом спросе.**

## Тупики

- **Каталог мини-приложений VK** ([vk.ru/services](https://vk.ru/services)): музыкальной категории нет, в выдаче из музыкального только «Подписка на VK Музыку», «VK Билеты», «Афиша», «Песня моего ДР» (развлечение: «А какая песня была популярной в день Вашего рождения?»). Поиск по каталогу и число пользователей без входа не показываются. Музыкальных мини-приложений сторонних разработчиков, которыми пользуются массово, не нашёл — вывод прошлого отчёта подтверждаю.
- **Smart-ссылки для артистов** — закрыто: BandLink (продукт Яндекса) — 3,2 млн визитов за август 2026, 78,09 % из России (Similarweb), бесплатный, с ботом `@bl_release_bot` по UPC. Жалоб не нашёл, один вопрос новичка в паблике FreshTunes (29.10.2024).
- **Genius** — целиком не заблокирован; РКН 21.07.2026 заблокировал одну аннотацию (Meduza, по выдаче). Подсказка «genius не работает в россии» есть, но живых вопросов не нашёл.
- **Список дизлайков** (+2 943), **совместные плейлисты** (+3 469), **интеграция с Discord** (+1 675), **совместное прослушивание** (+1 283) — спрос большой, но всё это внутри закрытого аккаунта; бот в Telegram без ключа пользователя ничего не может.
- **Оплата Spotify / Apple Music из России** — спрос огромный (Т—Ж, 26.01.2026: пять способов, посредники дороже на 50–300 %), но это посредничество в платежах, не функция музыкального бота.
- **Итоги года** — сезонно (декабрь) и закрыто самими площадками.
- **Афиши** — отвергнуто заранее, не искал.
- Потеря медиатеки Apple Music при смене страны (Хабр, 10.08.2026, охват 9,2 тыс., 4 комментария) — единичный случай.
